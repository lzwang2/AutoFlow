## 首版取舍

- 运行期间通用编辑区域只读；左侧仍可切页，顶部停止入口与 F10 保持可用。停止后恢复编辑。
- 对已有脚本和库编辑采用保守保存提示，暂未实现细粒度脏标记，因此部分已保存内容也可能提示确认。
- 预置任务不支持加载自定义基线，编辑后的副本不自动同步回来。
- 实际多人场景至少检查房间列表、无房列表、房间内、战斗和结算；本次无 Last Cloudia 目标窗口，未执行这些操作。
