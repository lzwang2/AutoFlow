# 按条件区域重新截图

## 行为

在「图像条件库」中导入并选中已有条件，选中游戏窗口并开始捕获，在目标画面出现时点击「按当前区域截图并覆盖」。无需再次框选，成功提示显示实际覆盖路径，日志在写入完成后记录该路径。

快捷截图按所选条件的 `ReferenceOuterWidth/Height` 和 `RegionX1..Y2` 换算到当前捕获帧，不使用编辑器当前脚本的参照尺寸。条件没有有效参照尺寸、区域超出画面或图片不存在时，报告失败，不修改图片。

仅覆盖条件当前指向的图片文件；不修改条件对象、图片路径、区域、阈值或条件 JSON。运行任务期间不可使用。手动框选和确认保存的原流程不变。

应用默认使用运行目录的模板库。运行目录重新截图不会自动写回源码；需要纳入工程的图片应另行复制回源码模板库。

## 验证

自动测试用不同大小的参照空间和捕获帧验证裁剪内容及尺寸，验证条件对象与 JSON 保持不变，以及无效参照尺寸不会覆盖已有图片。真实游戏界面与按钮交互需要实机观察。
