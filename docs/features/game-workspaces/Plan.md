# 游戏专用界面实施计划

- 日期：2026-11-14
- 状态：阶段 1–5 已实现；阶段 6 基础验证完成，真实游戏验收待完成
- 校验：2026-11-14 已与 Spec 和现有执行入口复核；以下为实施要求，尚未验证完成
- 行为及验收来源：[Spec.md](Spec.md)

## 1. 实施原则

先确认规范，再分阶段实现。保留通用编辑器功能，首版只落地 Last Cloudia 多人游戏面板。2026-11-15 已完成阶段 1–5 的首版实现，以及阶段 6 的构建、自动化测试和布局检查；真实游戏场景保留为未验证。

## 2. 阶段安排

| 阶段 | 工作与交付物 | 验证 |
|---|---|---|
| 1. 执行边界整理 | 调查 `MainViewModel`、窗口捕获生命周期、F9/F10 和关闭清理逻辑；提取共享运行协调器及完整脚本、引用库快照入口；启动前占用槽位并创建取消令牌，独立传入窗口和坐标上下文 | 现有线性与规则运行、取消和资源释放保持可用；开始、停止并发请求不会产生第二个任务；启动取消后不会迟到执行；AC-11、13 |
| 2. 应用导航 | 为 `MainWindow` 增加左侧导航，保留编辑器页面及其内部标签；共享窗口、状态和停止入口 | 切页后编辑内容、选中项及运行状态保留；编辑器新建、打开、保存和另存为回归 |
| 3. 游戏资源与预检 | 配置预置脚本的构建/发布复制；实现无窗口副作用的完整脚本加载，独立加载 Last Cloudia 引用库，补充格式、共享图片和技能图片预检 | 快照保留源脚本的全部规则和参数；缺失资源或无效引用可定位错误；AC-07、08、10 |
| 4. 游戏专用面板 | 增加完整多人游戏任务卡、开始/停止入口和加载/运行状态，不提供配置项；接入共享运行能力和目标匹配的捕获会话；将实测客户区传入独立坐标上下文；修改 `MainWindow.xaml.cs` 的全局热键路由 | AC-02、03、04、08、09、11、13；F9 按当前页面启动，F10 停止全局任务；环境控件禁用符合 Spec |
| 5. 编辑器衔接 | “在编辑器中打开”传递完整脚本独立副本，处理未保存文档及受影响的库编辑；保存操作返回成功／取消／失败结果；检查加载、构建和保存链路保留全部字段；不新增专用用户配置文件 | AC-05、06、12；取消或保存失败不切换页面、不替换文档；编辑和运行的副本互不污染 |
| 6. 集成验收 | 检查仓库外启动、发布包和真实游戏场景，更新文档与测试记录 | 按 Spec 全部验收项记录通过、失败或未验证，不能用构建成功代替实际游戏验收 |

## 3. 验证策略

- 有意义的自动验证集中在完整脚本快照、深拷贝隔离、必要资源校验以及单任务互斥；复用现有测试工程和可注入依赖，避免依赖真实游戏完成单元测试。
- 执行适用的现有测试和 Release 构建；发布到独立临时目录，从仓库外启动，确认打包路径和资源解析。
- 手工检查两个页面切换、窗口选择、日志、运行/停止、快捷键、重复开始、错误恢复及未保存提示。
- 专项验证：启动等待期间按 F10；捕获已指向其他窗口；编辑器选中其他游戏后进入面板；运行时编辑共享条件和动作；保存对话框取消及写入失败；副本另存到仓库外后重新打开。逐项对应 AC-10 至 AC-13。
- 在 Last Cloudia 中核对房间列表、无房列表、房间内/战斗/结算三类场景。按预置脚本的现有参与者参数执行，不增加或验收房主模式切换。

## 4. 风险与处理

| 风险 | 处理 |
|---|---|
| 主视图模型集中管理过多状态，导航重建导致运行丢失 | 先梳理生命周期并抽出共享运行所有权，页面切换复用视图模型 |
| 预置脚本依赖共享条件及技能图片 | 以引用闭包检查发布包，不只复制 JSON |
| 面板错误拆分内部规则或覆盖技能参数 | 完整加载脚本，不增加按规则名称改写及参数映射逻辑 |
| 编辑器和专用面板共享可变对象 | 使用独立脚本快照，明确副本保存位置 |
| 外框和客户区混淆导致图像匹配失效 | 沿用窗口测量和坐标转换，显示实测客户区 |
| 复用编辑器打开流程导致预加载改变窗口及持久化偏好 | 分离纯数据加载与运行前窗口准备，不通过编辑器绑定属性传递专用任务尺寸 |
| 既有规则运行／保存构建器丢失完整脚本字段 | 对比源文件、运行快照及副本另存再加载后的语义，覆盖元数据、IdleTickMs、规则和动作内容 |
| 技能图片缺失无法从 ConditionRef 发现 | 单独检查已知 Last Cloudia 技能资源，并验证输出和发布清单 |
| 真实游戏场景无法随时复现 | 自动验证与实际游戏验收分别记录，明确未验证项 |

## 5. 完成记录要求

实现后补充实际修改模块、构建和测试命令及结果、AC 逐项结论、已知限制。设计变化先更新规范，不能只在实施计划中改变用户行为。

## 6. 首版实现与验证（2026-11-15）

- 导航与共享任务入口：`MainWindow.xaml`、`MainViewModel.Workspaces.cs`；同一执行槽覆盖启动、运行与清理，F9 复用当前页面的命令，F10 复用全局停止命令。
- 游戏独立视图及模型：`LastCloudiaView`、`LastCloudiaViewModel`。完整脚本通过 `GameTaskScript` 加载及预检，游戏资源由 AppBase 解析。
- 执行隔离：脚本、条件、动作快照，捕获窗口／方式匹配，窗口句柄固定，独立坐标上下文；每轮开始重置技能跨帧状态。编辑区域在运行时只读，停止后恢复。
- 编辑器衔接：保留规则文档头及元数据，保存取消／失败保留原内容；首版使用保守保存提示，未实现精细的文档脏标记。
- 验证结果及命令：[首版验证记录](../../testing/GameWorkspaces_Validation.md)。通过 272 项核心测试、5 项 WPF／视图模型测试；7 项历史迁移测试保持原有跳过设置。真实游戏行为和完整桌面交互验收尚未完成。
